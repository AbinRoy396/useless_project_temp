## Project Description

**PrinciPain** is an anonymous student-feedback platform that transforms everyday campus frustrations into measurable institutional insights.

Students submit problems anonymously. The system categorizes complaints, calculates a **Campus Frustration Index**, creates daily reports, and generates a respectful **Principal Roast** based on recurring institutional issues.

Because apparently, the best way to solve student problems is to first give them a dashboard.

---

## The Problem (that doesn't exist)

Students have problems.

Lots of them.

Broken equipment, timetable chaos, Wi-Fi disappearing exactly when an assignment is due, questionable canteen decisions, mysterious attendance rules, and other completely fictional campus inconveniences.

The actual problem?

Nobody knows **how frustrated everyone really is**.

Reading hundreds of complaints manually is clearly not a sufficiently advanced use of technology.

---

## The Solution (that nobody asked for)

Enter **PrinciPain**.

Students anonymously submit frustrations through the platform.

The system then:

- Categorizes the complaint
- Detects sentiment
- Measures severity
- Calculates a frustration score
- Generates a concise summary
- Aggregates campus-wide frustration
- Identifies recurring institutional problems
- Generates daily administrative reports
- Produces a respectful aggregate-based Principal Roast
- Allows administrators to review and approve reports
- Provides an audited email-dispatch workflow

The result is a campus command center where student frustration becomes data.

And occasionally, comedy.
